# Multi-Path-Neural-Networks-on-Bare-Metal-Microcontroller
Telemetry-driven, resource-adaptive Edge AI framework for ESP32-S3 MCUs. Features joint-trained multi-path neural networks ($\mathcal{P}_{\text{small}}$, $\mathcal{P}_{\text{medium}}$, $\mathcal{P}_{\text{large}}$) governed by a dual-trigger closed-loop gating engine for zero-malloc bare-metal C++ inference.
